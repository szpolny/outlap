# Series marks

Single-colour marks used as CSS masks by `SeriesLogo.svelte`: black on transparent, trimmed and
72 px high. Each was made from the series' own artwork by keeping its shapes and dropping
backgrounds; some are cropped to the series' wordmark.

Sources of the marks added in October 2026 (second batch):
